# Garbage Collectors: A Deep Dive

**Author:** Anand Kumar Keshavan

---

This book takes you from the theory of automatic memory management to building three working garbage collectors in C. You'll implement mark-and-sweep, copying/generational collection, and a concurrent variant—and learn how they integrate with the LLVM runtime.

Whether you're curious how languages like Java, Go, or Python manage memory, or you're building a language or runtime yourself, this deep dive will give you the foundations and the code.
